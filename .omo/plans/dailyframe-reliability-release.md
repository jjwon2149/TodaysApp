## 수용 기준
실패 후 원본/썸네일 복구, 정상 재동기화 시 중복 전송 방지, 삭제 부활 방지, 최신 편집 보존, 실패 시 정상 미디어 보존, 비활성화 시 원격 접근 금지. 홈 실패는 0개/0일로 오인되지 않으며 재시도로 회복. 완료 문구는 저장/수정 사실과 확인된 스트릭만 표시한다.

## 검증
`xcodebuild test -project DailyFrame/DailyFrame.xcodeproj -scheme DailyFrame -destination 'platform=iOS Simulator,name=iPhone 16,OS=18.5'`
미설치 환경은 실제 사용 가능한 시뮬레이터 ID를 사용하고 기록한다. UI/실기기/출시 절차는 docs/reliability-release-checklist.md에 기록한다. 테스트 미실행을 PASS로 취급하지 않는다.

## 결과와 잔여 조건
현재 구현/자동 검증 결과는 `docs/reliability-release-results.md` 참조. 홈 정상/읽기 실패 화면은 시뮬레이터로 확인했다. 전체 화면 회귀와 실제 배포는 미완료다. 동기화 도중 새 변경이 들어오면 미완료 상태에서 다음 수동/실행 동기화를 요구할 수 있다. 서로 다른 활성 기록의 동일 수정시간 동률 정책은 후속 설계 대상으로 남긴다.
